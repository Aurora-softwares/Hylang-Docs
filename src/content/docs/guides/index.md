# Learn by doing

Looking for a simple way to learn Hydrogen? These walkthroughs help you build confidence, one task at a time.

- **[Write your first program](/guides/first-project/)** — Download a tiny example, edit it, and run it.
- **[Install Hydrogen](/getting-started/installing/)** — Set up the published compiler.
- **[Compile an executable](/getting-started/compiling/)** — Turn Hydrogen code into a native program.
- **[Organize a project](/tools/projects/)** — Add a project manifest and multiple source files.
- **[Explore desktop UI (Development)](/tools/desktop-ui/)** — Learn about ongoing native desktop application support.

If something does not work as described, check the [current release](/getting-started/current-release/). Some advanced features are still part of the development compiler.
