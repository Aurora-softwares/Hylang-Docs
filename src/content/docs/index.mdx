Hydrogen, also called Hylang, is a C#-inspired language built around namespaces,
classes, structs, and methods. Its released compiler is written in Hydrogen itself.
The current release is [`alpha-0.0.2`](https://github.com/Aurora-Softwares/Hylang-Compiler/releases/tag/alpha-0.0.2).
Use it to build Linux-native programs and early Australis firmware and kernel images.

## The current milestone

The released compiler runs on Linux x86-64 and directly emits standalone Linux
x86-64 executables. Its `uefi-x64` target can create bootloader and early-kernel
images, including a constrained transition out of UEFI boot services and direct
framebuffer text. This is still a fixed compilation profile rather than a complete
UEFI library or a general operating-system kernel.

Australis OS and native Australis applications are the primary direction. Linux
is the development host today; Windows and macOS compiler ports will follow when
they can be properly packaged and validated.
