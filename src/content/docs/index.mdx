Hydrogen, also called Hylang, is a C#-inspired language built around namespaces,
classes, and methods. Its released compiler is written in Hydrogen itself. Use it
to build Linux-native programs now and to help build the firmware and kernel layers
of Australis OS next.

## The current milestone

The released compiler runs on Linux x86-64 and directly emits standalone Linux
x86-64 executables. Its `uefi-x64` target can also create a bootable UEFI text
console Hello World. This is a real compiler-to-firmware milestone, but not yet a
complete UEFI library or an independent operating-system kernel.

Australis OS and native Australis applications are the primary direction. Linux
is the development host today; Windows and macOS compiler ports will follow when
they can be properly packaged and validated.
